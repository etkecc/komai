# Spanish translation instructions

These supplement the common rules; follow the existing translated strings as the primary reference.

## Register

Prefer **impersonal** constructions ("No se ha podido...", "Se ha expulsado a %1") — this matches the existing translations, which avoid direct address where possible. When direct address is unavoidable, use **informal "tú"** (modern FOSS convention).

## Typography

- Use `¡ !` and `¿ ?` inverted marks for exclamations/questions (standard Spanish).
- The existing translations use ASCII `...` for ellipsis — continue that convention unless the source uses `…`.
- Buttons/labels: use infinitive ("Aceptar", "Cancelar", "Guardar").
