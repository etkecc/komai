# Architecture Research

Forward-looking research on features that may or may not be implemented.

These docs differ from the rest of `docs/architecture/`:

- They describe how a feature **could** work, not how it works today.
- They are not commitments. Approach, scope, and priority are all subject to change.
- They graduate to a regular `docs/architecture/<feature>.md` (and this entry is removed) when the feature lands.

If you are reading one of these and want to influence the direction, the linked GitHub issue is the right place to comment.
