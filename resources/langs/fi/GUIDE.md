# Finnish translation instructions

These supplement the common rules; follow the existing translated strings as the primary reference.

## Register

Finnish UI typically uses **passive / impersonal** constructions ("Tätä viestiä ei ole salattu!", "Huoneeseen liittyminen epäonnistui"). Follow that convention. When direct address is unavoidable, use **informal "sinä"**.

## Typography

- Use the **horizontal ellipsis `…`** (U+2026) where possible.
- For quotes, follow the common GUIDE's rule (prefer ASCII in JSON); Finnish's typographic convention uses `"..."` (U+201D on both ends — same glyph opening and closing).
- Buttons/labels: imperative ("Tallenna", "Peruuta", "Lähetä").
