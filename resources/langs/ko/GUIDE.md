# Korean translation instructions

These supplement the common rules. No prior translations exist to mine — translate fresh, following modern Korean UI conventions.

## Register

Use the **해요/합니다 polite form (존댓말)** for full sentences — standard in Korean software. For button labels and short UI commands, drop sentence-final politeness and use the noun/verb stem form ("저장", "취소", "전송").

- "Failed to join room: %1" → "방에 참여하지 못했습니다: %1"
- "Save" (button) → "저장"
- "Are you sure?" → "정말 하시겠습니까?"

Do not use plain (반말) or extremely formal (하십시오체) forms.

## Typography

- Use the **horizontal ellipsis `…`** (U+2026), not `...`.
- Korean uses regular ASCII punctuation `. , ? !` (not full-width forms).
- Put a space between Korean text and Latin-script tokens / placeholders where natural (e.g., `사용자 %1`).
- Quoted text: use `"…"` (ASCII) or Korean-style `「…」`.
