# Simplified Chinese translation instructions

These supplement the common rules; follow the existing translated strings as the primary reference.

## Register

Chinese has no T-V distinction. Use the second person **你** when direct address is needed; existing translations mostly use impersonal constructions — prefer those.

## Matrix / chat vocabulary

| English | Simplified Chinese |
|---|---|
| room (chat) | **聊天室** (the existing translations use this — not the literal 房间) |
| space | **空间** |
| thread | **话题** or **线程** |
| direct message, DM | **私信** |
| invite (verb / noun) | **邀请** |
| join (a room) | **加入** |
| leave (a room) | **离开** |
| redact (= delete a message) | **删除** |
| encryption | **加密** |
| encrypted | **已加密** / **加密的** |
| verify / verification / verified (E2EE) | **验证** / **已验证** |
| user | **用户** |
| message | **消息** |
| device | **设备** |

## Typography

- Use **full-width Chinese punctuation**: `，。！？；：（）` — not ASCII `,.!?;:()`.
- Use full-width quotes **「」** or **""** for quoted text.
- The colon before values/parameters is often written as `：` (full-width), matching the existing translations (`"踢出用户：%1"`).
- Ellipsis: **`……`** (two U+2026 characters, Chinese convention) or a single `…` — follow what the existing translation uses in similar contexts.
- No space between Chinese text and placeholders: `踢出用户：%1` (no space around `：`).
