# Esperanto translation instructions

These supplement the common rules; follow the existing translated strings as the primary reference.

## Register

Esperanto uses **"vi"** for both singular and plural, formal and informal — there is no T-V distinction.

## Matrix / chat vocabulary

| English | Esperanto |
|---|---|
| room | **ĉambro** (pl. **ĉambroj**) |
| space | **spaco** |
| thread | **fadeno** |
| direct message, DM | **rekta mesaĝo** |
| invite (verb / noun) | **inviti** / **invito** |
| join (a room) | **aliĝi al** |
| leave (a room) | **forlasi** |
| redact (= delete a message) | **forigi** |
| encryption | **ĉifrado** |
| encrypted | **ĉifrita** |
| verify / verification / verified (E2EE) | **kontroli** / **kontrolo** / **kontrolita** (the existing translations use these; "verifiki" is an alternative) |
| user | **uzanto** |
| message | **mesaĝo** |
| device | **aparato** |

## Typography

- Use the **horizontal ellipsis `…`** (U+2026) — the existing translations already prefer this.
- Buttons/labels: use infinitive ("Konservi", "Nuligi", "Sendi").
