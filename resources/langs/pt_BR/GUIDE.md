# Brazilian Portuguese translation instructions

These supplement the common rules; follow the existing translated strings as the primary reference.

**Important**: this is **Brazilian Portuguese (pt_BR)** — distinct from European Portuguese (pt_PT). Use Brazilian spelling and vocabulary.

## Register

Use **"você"** for direct address (standard Brazilian UI register — polite without distance, universal default). The existing translations are mostly impersonal; follow suit where possible.

## Matrix / chat vocabulary (Brazilian forms)

| English | pt_BR |
|---|---|
| room | **sala** (pl. **salas**) |
| space | **espaço** |
| thread | **tópico** or **thread** |
| direct message, DM | **mensagem direta** |
| invite (verb / noun) | **convidar** / **convite** |
| join (a room) | **entrar na** |
| leave (a room) | **sair da** |
| redact (= delete a message) | **excluir** / **remover** |
| encryption | **criptografia** (pt_BR) — **not** "encriptação" (pt_PT) |
| encrypted | **criptografada/o** — **not** "encriptada" (pt_PT) |
| verify / verification / verified (E2EE) | **verificar** / **verificação** / **verificada/o** |
| user | **usuário** (pt_BR) — **not** "utilizador" (pt_PT) |
| message | **mensagem** |
| device | **dispositivo** |

## Typography

- Use the **horizontal ellipsis `…`** (U+2026) where possible — the existing translations prefer it.
- Buttons/labels: use infinitive ("Salvar", "Cancelar", "Enviar").
